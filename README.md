# 💰 FinLedger — B2B Invoicing & Financial Operations Portal

Enterprise B2B invoicing and financial reconciliation engine.

## API Reference
- `POST /api/v1/auth/register` - Create tenant organization
- `GET /api/v1/clients` - List client directory
- `POST /api/v1/invoices` - Issue invoice
- `POST /api/v1/payments` - Record settlement
- `GET /api/v1/analytics/summary` - AR summary metrics
